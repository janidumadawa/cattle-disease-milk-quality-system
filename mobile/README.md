# MedFarm Flutter App

Initial Flutter UI shell for the cattle disease and milk quality research project.

## Requirements

Install Flutter and the Android development prerequisites, then verify the environment:

```shell
flutter doctor
```

## Finish local platform setup

This starter contains the app package manifest and Dart entry point. From this directory, run:

```shell
flutter create --platforms=android,ios,web .
flutter pub get
flutter run
```

Choose an available device when prompted. Commit platform scaffolding generated by Flutter if the team plans to use it. Review generated files before committing.

## Current status

The dashboard is a UI placeholder. It does not call the backend, show real sensor values, or make milk-quality classifications yet. Those will be added against the agreed API contract.
